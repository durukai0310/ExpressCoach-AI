> 💡 今晚是W3最硬核的——实现自动评分

### 步骤1: 实现 LLM-as-Judge 自动评分 (20:00-21:30)

创建 `src/evaluate/judge.js`:
```
评分维度 (5维 × 5分 = 25分):
  1. 意图达成度 (Did they achieve the goal?)
  2. 关系维护度 (Did they protect the relationship?)
  3. 表达自然度 (Does it sound like a real human?)
  4. 策略适当性 (Is the strategy right for this relationship?)
  5. 可操作性 (Can the user actually say this?)

调用 GPT-4o/DeepSeek 做裁判，System Prompt 要求严格按5维度输出JSON
```
