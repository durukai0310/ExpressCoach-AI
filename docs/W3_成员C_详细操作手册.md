## 📋 Day 16 周二 6/16 | 社交计算白皮书初稿 (20:00-22:00)

> 💡 今晚写W3最重要的文档——解释"为什么社交计算比NLU更难"

### 步骤1: 撰写白皮书框架 (20:00-21:00)

打开 `docs/w3/social-computing.md`:

```
# ExpressCoach 社交计算引擎技术白皮书

## 1. 问题定义: 为什么社交表达比自然语言理解更难
- NLU只需要理解"说什么"
- 社交计算需要理解"对谁说、什么关系、什么时机、什么方式"
- 举例: "我不去"三个字 → 对朋友说OK, 对老板说需要30字铺垫

## 2. 技术路线: 规则锚点 + LLM精调 混合架构
- 为什么不用纯LLM: 幻觉、不可控、缺乏结构化推理
- 为什么不用纯规则: 覆盖率有限、无法处理模糊场景
- 混合模式: 规则提供"社交常识锚点", LLM在锚点附近做精调

## 3. 四维度社交计算模型
- 亲密度 (intimacy): 4级 — 决定说话的直接程度
- 权力关系 (power): 4级 — 决定说话的尊卑策略
- 利益关联 (interest): 3级 — 决定是否有谈判空间
- 表达敏感度 (sensitivity): 3级 — 综合前三个维度计算得出
- 4×4×3 = 48种组合 × 5种意图 = 240种社交场景矩阵

## 4. 策略映射引擎
- 规则词典: 32种关系 × 三维度标注
- LLM精调: 在规则锚点附近微调
- 三版本策略分化: 温和/坚定/高情商 → 不同场景自动推荐
```

### 步骤2: 画架构图 + 找案例 (21:00-22:00)

  3. 混合架构图 (规则层 + LLM层 + 融合层)

找3个典型案例:

## 📋 Day 18 周四 6/18 | 创新点论证文档 (20:00-22:00)

> 💡 今晚写"为什么我们不可替代"——答辩Q4的答案

### 步骤1: 撰写创新点文档 (20:00-21:30)

打开 `docs/w3/innovation-claims.md`:

```
# ExpressCoach 核心技术不可替代性论证

## 创新点1: 社交关系结构化计算 (★★★★★)
- 竞品: 通用LLM不理解"和谁说话" → 对老板和对朋友用同样的语气
- 我们: 32种关系×3维度 → 策略自动差异化
- 证据: 同一场景"拒绝借钱"，对5种关系的回复策略完全不同 (见w2-competitive-baseline.md)

## 创新点2: 三版本策略分化生成 (★★★★☆)
- 竞品: 给出一个"最佳"答案 → 用户没得选
- 我们: 温和/坚定/高情商三种价值观 → 用户根据场景选
- 证据: Jaccard差异度均值<0.3 (差异显著), 三版本在10场景中风格鲜明度17.1/20

## 创新点3: 反应预测前瞻 (★★★★☆)
- 竞品: 只告诉你"怎么说" → 说完之后对方什么反应不关它事
- 我们: 预测3-5种对方反应 + 概率评估 + 应对建议
- 证据: 9组测试合理率88.9%

## 创新点4: 规则+LLM混合架构 (★★★★★)
- 纯规则: 准确但僵化 (78.9%)
- 纯LLM: 灵活但不可控 (88.9%)
- 混合: 既准确又灵活 (92.6%)
- 证据: 18组合 × 3模式对比数据 (w2-relationship-test-results.md)

## 创新点5: W3多Agent对话沙盒 (★★★★☆)
- 业界热点: CrewAI/AutoGen做任务链, 我们做社交对话
- 教练Agent: 关键时刻介入, 不干扰正常对话
- 模拟对方Agent: 三种性格可调, 上下文共享
```
