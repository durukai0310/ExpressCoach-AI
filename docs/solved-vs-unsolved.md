## 🔲 W3 计划 (6项)

### 🔲 1. 多Agent沙盒 (W3核心)
- **目标**: 基于CrewAI/AutoGen设计双Agent架构（教练Coach + 模拟对方Simulator）
- **关键难点**: 
  - 上下文窗口管理（10轮对话上限）
  - 教练介入时机判断（只在关键时刻介入）
  - 模拟对方性格参数可调（友善型/刁难型/回避型）
- **前置工作**: Day 13已完成架构预研 → `notes/w3-sandbox-architecture-design.md`

### 🔲 2. LLM-as-Judge自动评分
- **目标**: 用GPT-4o当裁判，自动给三版本打分
- **评分维度**: 是否达成意图 / 是否维护关系 / 表达自然度 / 策略适当性

### 🔲 3. 反馈学习闭环
- **目标**: 用户版本选择 + 星级评分 → 持续优化生成策略
- **技术路线**: 偏好数据收集 → 定期微调few-shot示例 → A/B测试验证

### 🔲 4. W3多Agent沙盒Bot原型
- **目标**: 可交互的对话沙盒MVP
- **功能**: 用户选择场景 → Coach旁白指导 → Simulator扮演对方 → 10轮对话 → 总结报告

### 🔲 5. 意图识别 + 关系判断并行化
- **目标**: 全流程从~7s降到<4s
- **方案**: 步骤1和步骤2无数据依赖 → Promise.all并行执行

### 🔲 6. 扩大测试覆盖
- **目标**: 50+场景测试集 + 自动化回归
- **包含**: 边界场景（空输入/超长/纯英文/emoji）、文化差异场景、极端困境

## ⚠️ 已知局限 (5项 + 应对方案)

### ⚠️ 1. 长期记忆缺失
| 项目 | 内容 |
|------|------|
| **严重度** | 高 |
| **现象** | 每次分析独立，无对话历史，无法学习用户偏好 |
| **影响** | 用户每次都是"第一次使用"，体验不够个性化 |
| **我们正在尝试的方案** | W3引入对话上下文窗口（最近3-5次分析）；W4考虑用户档案和偏好学习 |

### ⚠️ 2. 文化差异适配不足
| 项目 | 内容 |
|------|------|
| **严重度** | 中 |
| **现象** | 关系词典基于中国大陆社交规范，未覆盖台港澳、海外华人、跨文化场景 |
| **影响** | "拒长辈敬酒"等场景的策略可能不适用于其他文化背景 |
| **我们正在尝试的方案** | W4增加文化适配参数（地域/年龄/场景类型）；词典增加跨文化条目 |

### ⚠️ 3. 效果评估依赖人工
| 项目 | 内容 |
|------|------|
| **严重度** | 高 |
| **现象** | 三版本质量靠人工评判，无自动化指标 |
| **影响** | 无法规模化优化，每次改进需要手动测试 |
| **我们正在尝试的方案** | W3引入LLM-as-Judge自动评分（见W3计划#2）|

### ⚠️ 4. 极端社交困境覆盖不全
| 项目 | 内容 |
|------|------|
| **严重度** | 中 |
| **现象** | Day 13专项测试覆盖了5个极端场景（4通过/1勉强/0失败），但样本有限 |
| **影响** | 真实世界的社交困境远比5个场景复杂 |
| **我们正在尝试的方案** | W3扩展至20+困境场景；增加"道德困境"子类别；收集真实用户反馈 |

### ⚠️ 5. 全流程耗时超标
| 项目 | 内容 |
|------|------|
| **严重度** | 低（内部标准） |
| **现象** | 3个Demo场景平均7.08s，超5s目标约42% |
| **影响** | 交互体验略慢，但仍在可用范围 |
| **我们正在尝试的方案** | W3并行化意图+关系判断（见W3计划#5）；中期考虑高频场景缓存；长期探索小模型本地部署 |

### ⚠️ 6. 意图分类扩展性受限
| 项目 | 内容 |
|------|------|
| **严重度** | 中 |
| **现象** | Day 13发现"道歉/修复关系"场景不在5种意图中，被归为"反馈"（置信度仅65%） |
| **影响** | 5种意图的硬编码限制了场景覆盖范围 |
| **我们正在尝试的方案** | W3考虑可扩展意图体系（主意图+子类型）；或增加第6种"道歉/修复"意图 |
