## 一、安装指南

### 1.1 环境要求

| 项目 | 要求 | 备注 |
|------|------|------|
| 操作系统 | Windows 10/11 / macOS / Linux | 推荐 Windows 10+ |
| Node.js | ≥ 16.x | 推荐 LTS 版本 |
| npm | ≥ 8.x | 随 Node.js 安装 |
| 网络 | 稳定网络连接 | 支持 DeepSeek/千问/Kimi 任一即可 |

### 1.2 安装步骤

**步骤1：安装 Node.js**

前往 [Node.js 官网](https://nodejs.org/) 下载并安装 LTS 版本。安装完成后验证：

```bash
node --version   # 应显示 v16.x 或更高
npm --version    # 应显示 8.x 或更高
```

**步骤2：克隆项目**

```bash
git clone <项目仓库地址>
cd expresscoach
```

**步骤3：安装依赖**

```bash
npm install
```

**步骤4：配置环境变量**

复制 `.env.example` 为 `.env`，并填写至少一个 API Key：

```bash
cp .env.example .env
```

编辑 `.env` 文件（至少配置一个）：

```env
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
DASHSCOPE_API_KEY=your-dashscope-api-key-here
MOONSHOT_API_KEY=your-moonshot-api-key-here
```

> **注意**: 只需至少配置一个 API Key 即可运行。推荐 DeepSeek（免费额度最充足）。

### 1.3 启动方式

```bash
node src/index.js
```

成功启动后将看到以下界面：

```
╔══════════════════════════════════════════════════════╗
║     🎯 ExpressCoach AI — 社交表达教练 (MVP Day 24)    ║
║  全链路+沙盒+自动评分+反馈闭环+竞品对比+用户画像            ║
╚══════════════════════════════════════════════════════╝

  📝 输入场景，AI 分析意图、判断关系并生成三版本回复
  输入 /help 查看示例 | /stats 统计 | /sandbox 沙盒 | /quit 退出
```

### 1.4 常见安装问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| `npm install` 失败 | 网络问题 | `npm config set registry https://registry.npmmirror.com` |
| API Key 无效 | Key 错误或余额不足 | 检查 API Key 是否正确 |
| `Cannot find module` | 依赖未安装 | 重新执行 `npm install` |
| `至少配置一个 API Key` | 无可用模型 | 在 `.env` 中至少配置一个 Key |

## 二、快速上手（3分钟）

### 第一步：输入场景

启动后，直接输入你的社交困境：

```
💬 输入场景: 朋友向我借5000元应急，但我最近也有经济压力
```

### 第二步：查看分析结果

系统自动完成三步：

1. **意图识别 (M1)**：识别核心意图 + 辅助意图（Day 23 多标签）
2. **关系判断 (M2)**：规则(0.3) + LLM(0.7) 混合判断，覆盖32种关系类型
3. **三版本生成 (M3)**：并行生成三种版本 + Jaccard 差异度检查

```
【步骤1/3】意图识别完成 (1.5s)
  主意图: 拒绝 | 置信度: 95.0%

【步骤2/3】关系判断完成 (2.2s)
  关系类型: 好朋友 | 亲密度: 较近 | 权力: 平等 | 利益: 强利益

【步骤3/3】三版本并行生成
  🕊️ 温和版 (关系维护优先)
  🛡️ 坚定版 (立场明确优先)
  🎯 高情商版 (双赢导向)
```

## 三、全链路使用教程

### 3.1 系统架构

```
输入 → M1意图识别(LLM+规则兜底) → M2关系判断(规则+LLM混合)
     → M3三版本生成(并行+Jaccard差异度检查) → M5反应预测 → M7案例保存
     → 沙盒: Coach↔Simulator双Agent多轮对话
```

### 3.2 核心模块

#### M1：意图识别（5种主意图 + 辅助意图）

| 意图类型 | 示例场景 |
|----------|----------|
| 拒绝请求 | 拒绝借钱、拒绝帮忙 |
| 催促对方 | 催交报告、催付款 |
| 提出反馈 | 给领导提建议、给室友提意见 |
| 设立边界 | 设工作时间边界、设隐私边界 |
| 寻求帮助 | 向导师请假、向同事求助 |

#### M2：关系判断（规则+LLM混合，覆盖32种关系）

| 属性 | 取值范围 |
|------|----------|
| 关系类型 | 32种中文社交关系 |
| 亲密度 | 亲密/较近/一般/疏远 |
| 权力关系 | 对方上位/平等/己方上位 |
| 利益关联 | 强利益/弱利益/纯情感 |
| 表达敏感度 | 高敏感/中敏感/低敏感 |

#### M3：三版本并行生成（含Jaccard差异度检查，阈值0.7）

| 版本 | 图标 | 定位 |
|------|------|------|
| 温和版 | 🕊️ | 关系维护优先 |
| 坚定版 | 🛡️ | 立场明确优先 |
| 高情商版 | 🎯 | 双赢导向 |

#### M5：反应预测（5种反应类型）

| 反应类型 | 应对策略 |
|----------|----------|
| 接受 | 保持友好，结束对话 |
| 犹豫 | 坚定立场，提供替代方案 |
| 拒绝 | 重新评估策略 |
| 情绪化 | 冷静回应，降低冲突 |
| 转移话题 | 引导回正题 |

### 3.3 命令参考

| 命令 | 功能 |
|------|------|
| `/help` | 显示帮助信息 |
| `/quit` | 退出程序 |
| `/search` | 搜索案例库 |
| `/stats` | 显示系统统计 |
| `/sandbox` | 进入沙盒模式 |

## 四、沙盒三种模式教程

双Agent架构：Coach Agent（教练）↔ Simulator Agent（模拟对方）

### 4.1 自由模式（Free）

Coach 静默，Simulator 正常性格。

```bash
node src/sandbox/sandbox.js "同事拖延影响我进度" free
```

### 4.2 引导模式（Guided）

Coach 每2轮给一次建议。

```bash
node src/sandbox/sandbox.js "催同事交报告" guided friendly --rounds 5
```

### 4.3 压力模式（Stress）

Simulator 强制 hostile，Coach 仅在求助时介入。

```bash
node src/sandbox/sandbox.js "向老板提涨薪" stress hostile --rounds 5 --autopilot
```

## 五、评分解读指南

### 5.1 5维度评分体系（LLM-as-Judge，与人工评分 r=0.937）

| 维度 | 权重 | 满分 | 考察点 |
|------|------|------|--------|
| 意图达成度 | 25% | 5分 | 意图是否清晰传达 |
| 关系维护度 | 25% | 5分 | 是否维护或增进关系 |
| 表达自然度 | 20% | 5分 | 是否像真人说话 |
| 策略适当性 | 20% | 5分 | 策略是否匹配关系 |
| 可操作性 | 10% | 5分 | 是否可直接使用 |

总分 = 25分 → 百分制: 总分/25×100

| 60-69 | C | 及格 |

## 六、FAQ

### Q1：ExpressCoach 是什么？

专注于中文社交表达的AI教练，通过意图识别→关系判断→三版本生成→反应预测的推理链，帮助用户在复杂社交场景中得体表达。

### Q2：和 ChatGPT 有什么区别？

ChatGPT 是通用大语言模型，ExpressCoach 是垂直领域专家系统。我们内置了关系推理、面子协商、多Agent沙盒等能力——这些是通用LLM不具备的。

### Q3：为什么生成三个版本？

- 🕊️ 温和版：关系维护优先，适合高敏感场景
- 🛡️ 坚定版：立场明确优先，适合坚持底线
- 🎯 高情商版：双赢导向，兼顾目标和关系

### Q4：支持哪些 API？

至少配置一个即可：DeepSeek / 阿里云千问 (DashScope) / 月之暗面 Kimi (Moonshot)

### Q5：数据安全吗？

所有数据保存在本地 `data/expresscoach.sqlite`，不上传云端。
