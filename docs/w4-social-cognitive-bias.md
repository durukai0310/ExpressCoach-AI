**版本**: v1.0

**用途**: ExpressCoach 认知偏差识别与介入指导

---

## 一、认知偏差概述

认知偏差是人们在思考和决策过程中系统性的思维错误。在社交场景中，这些偏差会导致：
- 误解他人意图
- 做出不恰当的反应
- 损害人际关系

**ExpressCoach角色**: 识别用户可能存在的认知偏差，提供理性视角和替代方案

---

## 二、常见社交认知偏差与介入策略

### 1. 聚光灯效应 (Spotlight Effect)

**偏差描述**:
- 高估他人对自己外貌、行为和情绪的关注程度
- 相信自己是别人注意力的中心
- 放大自己的小失误或尴尬时刻

**典型表现**:
- "所有人都看到我刚才说错话了"
- "我今天穿得很奇怪，大家都在看我"
- "我的脸红了，别人肯定发现了"

**AI教练介入策略**:

| 介入方式 | 话术示例 |
|----------|----------|
| 事实纠正 | "其实没那么多人在意这件事，大家都在关注自己" |
| 视角转换 | "如果你看到别人这样，你会特别注意吗？" |
| 数据支持 | "研究表明，人们对他人的关注时间平均不超过30秒" |

**ExpressCoach应用**:
- **检测条件**: 用户表达过度自我关注或担心他人评价
- **介入时机**: 生成回复前提示用户
- **示例**: "在回复前，想和你说：其实对方可能并没有那么在意细节，保持自然就好。"

---

### 2. 读心术偏差 (Mind Reading)

**偏差描述**:
- 自以为知道别人在想什么
- 没有证据就推断他人的动机和感受
- 把自己的猜测当作事实

**典型表现**:
- "他不回消息肯定是生气了"
- "她那样说就是看不起我"
- "领导没表扬我，一定是对我不满意"

**AI教练介入策略**:

| 介入方式 | 话术示例 |
|----------|----------|
| 提问引导 | "你为什么会这么想？有什么证据吗？" |
| 替代解释 | "也有可能是他太忙了没看到消息" |
| 建议验证 | "你可以直接问TA，而不是猜" |

**ExpressCoach应用**:
- **检测条件**: 用户使用"肯定"、"一定"、"就是"等绝对化词汇描述他人想法
- **介入时机**: 分析用户输入时识别并提醒
- **示例**: "你提到对方'肯定生气了'，这可能是猜测。要不要考虑直接沟通确认一下？"

---

### 3. 灾难化思维 (Catastrophizing)

**偏差描述**:
- 将小问题放大成灾难性后果
- 想象最坏的情况并相信它会发生
- "如果...就完了"的思维模式

**典型表现**:
- "拒绝了TA，我们的关系就完了"
- "这次没做好，领导肯定要开除我"
- "如果我说错话，所有人都会讨厌我"

**AI教练介入策略**:

| 介入方式 | 话术示例 |
|----------|----------|
| 现实检验 | "最坏的情况是什么？真的会发生吗？" |
| 概率评估 | "这种情况发生的概率有多大？" |
| 应对规划 | "即使发生了，你可以怎么应对？" |

**ExpressCoach应用**:
- **检测条件**: 用户表达极端负面后果的担忧
- **介入时机**: 策略推荐前进行风险评估
- **示例**: "你担心拒绝后关系会破裂，但根据我们的分析，使用合适的策略可以将风险降到最低。"

---

### 4. 情绪推理 (Emotional Reasoning)

**偏差描述**:
- 将感受当作事实
- "我感觉是这样，所以一定是这样"
- 忽视客观证据

**典型表现**:
- "我感觉尴尬，所以一定很尴尬"
- "我觉得被冷落了，所以他们就是故意的"
- "我感到焦虑，所以事情一定很糟"

**AI教练介入策略**:

| 介入方式 | 话术示例 |
|----------|----------|
| 区分感受与事实 | "感觉不等于事实，让我们看看实际情况" |
| 证据检验 | "有什么证据支持你的感觉？" |
| 理性重建 | "你实际说的话并没有问题，是情绪在影响你" |

**ExpressCoach应用**:
- **检测条件**: 用户使用"我觉得"、"我感觉"来支持结论
- **介入时机**: 帮助用户区分情绪与事实
- **示例**: "我理解你现在感觉很紧张，但我们准备的回复是得体且有效的。"

---

### 5. 非黑即白思维 (All-or-Nothing)

**偏差描述**:
- 认为事情只有两种极端情况
- 忽视中间地带和灰色区域
- 使用绝对化的思维模式

**典型表现**:
- "要么忍，要么撕破脸"
- "如果不同意我的方案，就是不支持我"
- "要么完美，要么失败"

**AI教练介入策略**:

| 介入方式 | 话术示例 |
|----------|----------|
| 提供中间选项 | "其实还有很多中间选项" |
| 打破绝对化 | "事情不是非此即彼的" |
| 展示梯度 | "我们可以从温和到坚定有多个选择" |

**ExpressCoach应用**:
- **检测条件**: 用户表达极端二元选择
- **介入时机**: 提供三版本策略时
- **示例**: "你觉得只有'忍'和'撕破脸'两种选择，但我们有温和、坚定、高情商三种方案可以尝试。"

## 四、偏差检测规则

### 关键词触发

| 偏差类型 | 触发关键词 |
|----------|------------|
| 聚光灯效应 | 所有人、大家都、注意到、尴尬 |
| 读心术偏差 | 肯定、一定、就是、显然 |
| 灾难化思维 | 完了、糟了、毁了、完蛋 |
| 情绪推理 | 感觉、觉得、认为（主观） |
| 非黑即白 | 要么...要么、只有、只能 |

### 语境分析

- **程度词检测**: 过度、非常、极其、绝对
- **模态词检测**: 必须、一定、肯定、绝对
- **负面预测**: 会、将、肯定会、一定会

## 五、ExpressCoach集成方案

### 1. 实时偏差提醒

在用户输入后，系统分析是否存在认知偏差，提供温和提醒：

```json
{
  "has_bias": true,
  "bias_type": "catastrophizing",
  "confidence": 0.85,
  "message": "你似乎在担心最坏的情况。其实我们有多种策略可以降低风险。",
  "recommendation": "考虑使用温和版策略，既能表达立场又能维护关系。"
}
```

### 2. 策略调整

根据检测到的偏差，调整策略推荐：

| 偏差类型 | 策略调整 |
|----------|----------|
| 聚光灯效应 | 推荐更自然、放松的表达 |
| 读心术偏差 | 推荐包含确认意图的话术 |
| 灾难化思维 | 推荐风险最低的策略 |
| 情绪推理 | 提供理性视角的话术 |
| 非黑即白 | 强调中间选项的优势 |

### 3. 学习反馈

记录用户对偏差提醒的反应，优化检测准确率：

```json
{
  "user_id": "xxx",
  "bias_detected": "mind_reading",
  "user_accepted": true,
  "strategy_used": "温和版",
  "outcome_rating": 4
}
```

## 六、案例分析

### 案例1：读心术偏差

**用户输入**: "同事今天没跟我打招呼，肯定是对我有意见。"

**偏差检测**: 读心术偏差（肯定、对我有意见）

**教练反馈**: "你觉得同事对你有意见，这可能是猜测。要不要考虑直接问问TA？或者先用温和的方式打招呼测试一下？"

**策略推荐**: 温和版问候话术

---

### 案例2：灾难化思维

**用户输入**: "我要是拒绝领导的要求，肯定会被穿小鞋。"

**偏差检测**: 灾难化思维（肯定、穿小鞋）

**教练反馈**: "被穿小鞋的概率其实很低，而且我们可以用高情商的方式拒绝，既能表达困难又能维护关系。"

**策略推荐**: 高情商版拒绝话术

---

### 案例3：非黑即白思维

**用户输入**: "要么我忍了，要么就跟他吵架。"

**偏差检测**: 非黑即白（要么...要么）

**教练反馈**: "其实还有很多中间选项。比如可以温和地表达你的感受，或者设定明确的边界。"

**策略推荐**: 展示三版本策略对比
