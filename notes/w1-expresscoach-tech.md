## 1. 项目概述

**ExpressCoach AI** 是一款 AI 社交表达教练，帮助用户在复杂社交场景中找到最佳表达方式。用户输入社交场景描述，系统自动完成意图识别、关系判断，并以三种不同风格（温和版 / 坚定版 / 高情商版）并行生成回复建议。

### W1 目标
演示 "用户输入场景 → 意图识别 → 关系判断 → 三版本生成" 完整链路。

## 2. 技术架构

### 2.1 系统架构

```
┌─────────────────────────────────────────────────┐
│                  用户交互层                        │
│              CLI (Node.js + Emoji)               │
├─────────────────────────────────────────────────┤
│                ExpressCoach 核心层                │
│  ┌──────────┐  ┌──────────┐  ┌───────────────┐  │
│  │ 意图识别  │→│ 关系判断  │→│ 三版本并行生成  │  │
│  │ SOUL.md  │  │ SOUL.md  │  │ 3× SOUL.md    │  │
│  └──────────┘  └──────────┘  └───────────────┘  │
├─────────────────────────────────────────────────┤
│                  LLM API 层                       │
│            DeepSeek API (deepseek-chat)          │
├─────────────────────────────────────────────────┤
│                   数据层                           │
│              SQLite (W2 集成)                     │
└─────────────────────────────────────────────────┘
```

### 2.2 核心数据流

```
用户输入
  ↓
步骤1: 意图识别 Agent (SOUL.md)
  → 分析5种意图: 拒绝/催促/反馈/设边界/求助
  → 输出: 意图类型 + 置信度 + 分析 + 关键词
  ↓
步骤2: 关系判断 Agent (soul/relationship-judge.md)
  → 分析4维度: 亲密度/权力关系/利益关联/表达敏感度
  → 输出: 关系类型 + 策略建议 + 注意事项
  ↓
步骤3: 三版本并行生成 (Promise.all)
  → 🕊️ 温和版 (soul/generator-mild.md): 关系维护优先
  → 🛡️ 坚定版 (soul/generator-firm.md): 立场明确优先
  → 🎯 高情商版 (soul/generator-eq.md): 双赢导向
  → 每个版本融入关系判断结果
  ↓
格式化输出: 三版本并排对比 + 策略分析
```

## 3. SOUL.md 体系

| 文件 | 角色 | 用途 |
|------|------|------|
| `SOUL.md` | 意图识别专家 | 5种意图分类，JSON 输出 |
| `soul/relationship-judge.md` | 关系分析专家 | 4维度关系判断，输出策略建议 |
| `soul/generator-mild.md` | 温和版顾问 | 友善共情，关系维护优先 |
| `soul/generator-firm.md` | 坚定版顾问 | 直接清晰，立场明确优先 |
| `soul/generator-eq.md` | 高情商版顾问 | 智慧幽默，双赢导向 |

## 7. W1 技术亮点

1. **SOUL.md 驱动的多角色系统**: 5个独立 SOUL.md 定义不同 Agent 角色，风格差异化明显
2. **并行生成架构**: Promise.all 实现三版本并行调用，耗时 ≈ 单次调用时间
3. **关系感知生成**: 三版本生成时融入关系判断结果（亲密度/权力/利益），输出更精准
4. **完善的错误处理**: API 调用重试机制 + SOUL 解析容错 + 降级策略
5. **本地化友好**: 针对中文社交场景优化的意图分类和关系判断

---

## 8. W2 开发计划

1. **关系判断完善**: 增加更多关系类型（恋人/师生/亲戚等），提高判断准确率
2. **三版本质量提升**: 调整 temperature 和 prompt，输出更差异化
3. **反应预测系统**: 预测对方可能的反应 + 应对策略
4. **SQLite 集成**: 案例库存储 + 用户反馈收集 + 偏好学习
5. **CLI 美化**: 更丰富的颜色和排版
