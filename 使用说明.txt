一、环境要求
------------------------------------------------------------
- Node.js >= 22.19（必须，OpenClaw 框架最低要求；下载地址: https://nodejs.org）
- npm（随 Node.js 自动安装）
- Windows 10/11（macOS/Linux 可用命令行方式运行）


二、安装步骤
------------------------------------------------------------
1. 解压本压缩包到任意目录
2. 双击 "安装依赖.bat"（或命令行执行 npm install）
3. 注册 DeepSeek API Key：
   → 打开 https://platform.deepseek.com/
   → 注册/登录 → 进入 API Keys 页面
   → 创建 API Key，复制 sk-xxxx 那串
4. 将 .env.example 重命名为 .env，用记事本打开
   把 "sk-你的DeepSeek_API_Key填这里" 替换为你的 Key


三、启动方式
------------------------------------------------------------
【方式一】双击启动（最简单）
  双击 "启动.bat" → 输入场景 → 回车 → 看结果

【方式二】命令行启动
  npm start
  或 node src/index.js

【方式三】单次分析
  node src/index.js "我想拒绝朋友借钱但不想伤感情"

【方式四】Web 界面
  node src/server.js
  浏览器打开 http://localhost:3000


四、交互命令（CLI 模式）
------------------------------------------------------------
/help    查看示例场景和命令
/stats   查看系统统计（准确率等数据）
/search  搜索历史案例库
/quit    退出程序

六、API Key 配置（评委需自行免费注册，约2分钟）
------------------------------------------------------------
出于账号安全考虑，本压缩包不包含任何真实 API Key。
请按以下步骤免费获取（任选一个即可运行，推荐 DeepSeek）：

  1. 打开 https://platform.deepseek.com/ 注册/登录
  2. 进入 API Keys 页面 → 创建 API Key → 复制 sk-xxxx
  3. 将 .env.example 重命名为 .env，用记事本打开
  4. 把 "sk-你的DeepSeek_API_Key填这里" 替换为你的 Key
  5. 保存后双击 "启动.bat" 即可

说明：
  - DeepSeek 新用户注册送 500 万 tokens，每次分析约消耗
    4000 tokens，足够评测使用上千次
  - 也可配置千问(DASHSCOPE_API_KEY)或 Kimi(MOONSHOT_API_KEY)，
    在 .env 中填入对应 Key 即可切换模型


七、常见问题
------------------------------------------------------------
Q: 提示 "DEEPSEEK_API_KEY 未配置"
A: 注册 DeepSeek → 创建 Key → 填入 .env

Q: 提示 "node 不是内部命令"
A: 安装 Node.js，勾选 "Add to PATH"

Q: npm install 很慢
A: npm config set registry https://registry.npmmirror.com

Q: 双击 bat 闪退
A: 右键 bat 文件 → 编辑 → 检查路径是否正确


八、技术架构
------------------------------------------------------------
用户输入 → M1意图识别(5种) → M2关系判断(32种×3维)
→ M4三版本生成(温和/坚定/高情商) → M5反应预测(5种)
→ 格式化输出 + SQLite存储

技术栈: Node.js + DeepSeek API + SQLite + OpenClaw 框架
