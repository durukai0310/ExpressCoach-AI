# M4 策略生成模块

## 功能概述

策略生成模块（M4）是 ExpressCoach 的核心模块，负责基于意图和关系分析结果，生成三种不同风格的回复版本。该模块采用并行生成策略，确保三个版本具有明显的风格差异。

**核心功能**：
- 并行生成三种风格的回复：直接坦诚、委婉含蓄、幽默轻松
- 使用 Jaccard 相似度检测版本差异度
- 自动重试机制，确保生成质量
- 基于策略矩阵选择合适的策略模板
- 支持30种策略模板（S01-S30）

**设计目标**：
- 三版本差异度均值 ≥ 0.6
- 响应时间 < 5秒
- 覆盖所有意图×关系组合

### 并行生成

三个版本同时调用 LLM 生成，使用不同的提示词引导：

| 风格 | 提示词特征 | 温度参数 | 目标效果 |
|------|----------|---------|----------|
| 直接坦诚 | "直接表达意图，不绕弯子" | 0.3 | 清晰、明确 |
| 委婉含蓄 | "委婉表达，考虑对方面子" | 0.4 | 温和、得体 |
| 幽默轻松 | "用幽默方式化解尴尬" | 0.7 | 轻松、有趣 |

### Jaccard 差异度计算

```
Jaccard相似度 = |A ∩ B| / |A ∪ B|
差异度 = 1 - Jaccard相似度
```

- **目标差异度**：≥ 0.6（三个版本之间的平均差异度）
- **重新生成条件**：差异度 < 0.4 时触发重试

### 自动重试机制

- 最大重试次数：2次
- 重试策略：重新生成差异度最小的两个版本
- 温度调整：重试时增加温度参数，增加多样性

## 设计决策

### 三版本设计的原因

**用户需求差异**：
- 不同用户有不同的表达风格偏好
- 同一用户在不同场景下需要不同风格
- 提供选择空间，提高用户满意度

**场景适配**：
- 直接坦诚：适合紧急、明确的场景
- 委婉含蓄：适合需要维护关系的场景
- 幽默轻松：适合非正式、轻松的场景

### Jaccard 差异度的选择

相比余弦相似度，Jaccard 更适合文本差异度检测：
- 不考虑词频，只考虑词是否出现
- 更适合检测内容的实质性差异
- 计算简单，效率高

### 温度参数的差异化设置

不同风格使用不同温度：
- 直接坦诚：低温度（0.3），确保输出稳定
- 委婉含蓄：中温度（0.4），适度灵活
- 幽默轻松：高温度（0.7），增加创意

### 核心函数

**generateThreeVersions(scenario, intent, relation)**

```javascript
async function generateThreeVersions(scenario, intent, relation) {
  const strategy = matchStrategy(intent, relation);
  
  const promises = [
    generateVersion(scenario, intent, relation, strategy, "直接坦诚", 0.3),
    generateVersion(scenario, intent, relation, strategy, "委婉含蓄", 0.4),
    generateVersion(scenario, intent, relation, strategy, "幽默轻松", 0.7)
  ];
  
  const versions = await Promise.all(promises);
  
  const diversity = calculateDiversity(versions);
  
  if (diversity < 0.4) {
    return await regenerateLowDiversity(versions, scenario, intent, relation, strategy);
  }
  
  return { versions, strategy, diversity };
}
```

**matchStrategy(intent, relation)**

根据意图和关系选择最优策略模板。

**calculateDiversity(versions)**

计算三个版本之间的平均 Jaccard 差异度。

**regenerateLowDiversity(versions, ...)**

重新生成差异度不足的版本。

## 局限性

### 当前局限

1. **策略模板固定**：30种策略模板是预设的，无法动态生成新策略
2. **风格差异有限**：三种风格可能在某些场景下差异不够明显
3. **幽默策略风险**：幽默版本可能在正式场景中不合适
4. **并行调用成本**：三个版本并行调用增加了API成本
5. **中文语用学理解有限**：LLM对中文社交语用学的理解可能不够精准

### 改进方向

1. **动态策略生成**：基于用户反馈学习新策略模板
2. **风格参数化**：允许用户自定义风格参数
3. **场景适配过滤**：根据场景敏感度自动禁用幽默版本
4. **缓存机制**：缓存相似场景的生成结果，减少重复调用
5. **语用学增强**：引入中文社交语用学知识库，提升生成质量
