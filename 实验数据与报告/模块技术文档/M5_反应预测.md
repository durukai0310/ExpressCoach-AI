# M5 反应预测模块

## 功能概述

反应预测模块（M5）是 ExpressCoach 的差异化模块，负责预测用户选择的回复可能引起的对方反应。该模块帮助用户提前预判社交后果，做出更明智的决策。

**核心功能**：
- 预测5种反应类型：接受、犹豫、拒绝、情绪化、转移话题
- 评估每种反应的概率（高、中、低）
- 提供典型回复示例
- 给出应对策略建议
- 支持多种风格和版本
- 基于社交心理学理论构建预测模型

**设计目标**：
- 反应合理率 ≥ 85%
- 覆盖所有意图类型
- 提供可操作的应对策略

## 核心算法

### 算法架构

模块采用 **LLM 预测 + 概率模型** 策略，基于 `soul/predictor.md` 构建预测模型：

```
┌─────────────────────────────────────────────────────────────┐
│                    反应预测流程                              │
├─────────────────────────────────────────────────────────────┤
│  输入: 场景 + 选择的版本 + 风格                               │
│       │                                                     │
│       ▼                                                     │
│  ┌──────────────┐                                          │
│  │ 构建预测输入  │  → JSON格式输入                           │
│  └──────┬───────┘                                          │
│         │                                                  │
│         ▼                                                  │
│  ┌──────────────┐                                          │
│  │ 调用DeepSeek │  → 使用predictor.md提示词                  │
│  └──────┬───────┘                                          │
│         │                                                  │
│         ▼                                                  │
│  ┌──────────────┐                                          │
│  │ 解析预测结果  │  → 提取5种反应类型                         │
│  └──────┬───────┘                                          │
│         │                                                  │
│         ▼                                                  │
│  输出: 反应类型、概率、典型回复、应对策略                       │
└─────────────────────────────────────────────────────────────┘
```

### 反应类型定义

基于社交心理学研究，覆盖主要反应模式：

| 类型 | 定义 | 典型场景 | 应对策略 |
|------|------|----------|----------|
| 接受 | 对方同意请求或接受反馈 | 温和拒绝→对方理解 | 确认共识，推进下一步 |
| 犹豫 | 对方不确定，需要进一步沟通 | 高情商版→对方考虑 | 提供更多信息，降低决策难度 |
| 拒绝 | 对方拒绝或反驳 | 坚定版→对方不满 | 保持冷静，准备备选方案 |
| 情绪化 | 对方产生负面情绪 | 直接拒绝→对方生气 | 安抚情绪，解释立场 |
| 转移话题 | 对方回避问题 | 尴尬场景→转移话题 | 重新聚焦，或暂时搁置 |

### 概率判断逻辑

- **高概率**（>70%）：最可能发生的反应
- **中概率**（30%-70%）：可能发生的反应
- **低概率**（<30%）：不太可能发生的反应

### 应对策略生成

基于反应类型和场景特征，生成针对性的应对策略：
1. **接受反应**：确认共识，推进下一步
2. **犹豫反应**：提供更多信息，降低决策难度
3. **拒绝反应**：保持冷静，准备备选方案
4. **情绪化反应**：安抚情绪，解释立场
5. **转移话题**：重新聚焦，或暂时搁置

## 设计决策

### 为什么需要反应预测？

**用户痛点**：
- 不知道对方会怎么反应
- 担心伤害关系
- 需要提前准备应对策略

**模块价值**：
- 降低社交风险
- 提高决策信心
- 提供应对预案

### 5种反应类型的选择

基于社交心理学研究，覆盖主要反应模式：
- 积极反应（接受）
- 中性反应（犹豫、转移话题）
- 消极反应（拒绝、情绪化）

### 温度参数设置

选择 `temperature: 0.3` 的原因：
- 反应预测需要一定的多样性
- 不同反应类型需要体现差异
- 避免过度随机导致不可用

### 概率数值化

除了文本概率（high/medium/low），还提供数值概率：
- 便于后续分析和排序
- 支持概率阈值筛选
- 提高预测的精确性

### 核心函数

**predictReactions(scenario, selectedVersion, style, relation)**

```javascript
async function predictReactions(scenario, selectedVersion, style, relation = null) {
  const soulContent = loadFile(PREDICTOR_SOUL, "predictor.md");
  
  const userInput = JSON.stringify({
    scenario: scenario,
    selected_version: selectedVersion,
    style: style,
    relation: relation || {}
  });
  
  const { content } = await callDeepSeek(soulContent, userInput, {
    temperature: 0.3,
    maxTokens: 500,
    maxRetries: 2
  });
  
  const result = parseResponse(content);
  
  return { raw: content, parsed: result.predictions, error: null };
}
```

**parseResponse(raw)**

三层解析策略，确保 JSON 响应的鲁棒解析。

## 局限性

### 当前局限

1. **反应类型有限**：仅支持5种反应类型，无法覆盖所有可能的反应
2. **概率准确性有限**：基于LLM预测，概率数值的准确性无法保证
3. **应对策略通用化**：应对策略较为通用，缺乏个性化定制
4. **上下文缺失**：无法考虑对话历史和对方性格特征
5. **文化差异**：基于中国文化背景，国际化场景可能不适用

### 改进方向

1. **扩展反应类型**：增加更多细分反应（如协商、妥协、质疑等）
2. **概率校准**：基于用户反馈校准概率预测模型
3. **个性化策略**：根据用户特征和关系历史生成个性化应对策略
4. **上下文记忆**：引入对话历史，支持多轮反应预测
5. **文化适配**：根据用户地区自动调整预测规则
