# M6 对话沙盒模块

## 功能概述

对话沙盒模块（M6）是 ExpressCoach 的用户交互界面模块，负责提供三种不同模式的使用体验。该模块是用户与系统交互的核心入口，设计目标是提供直观、友好、高效的操作体验。

**核心功能**：
- 自由模式：用户自由输入场景，系统自动分析
- 引导模式：结构化分析框架，适合复杂场景
- 压力模式：紧急场景优化，快速响应
- 双Agent模拟：用户可以与模拟的对方进行对话练习
- 情绪追踪：实时追踪对话中的情绪变化
- 命令系统：支持 /help、/quit、/search、/stats、/clear
- 用户输入处理和错误处理

**设计目标**：
- 操作简单直观
- 响应时间 < 7秒
- 支持多种使用场景
- 情绪追踪准确率 ≥ 80%

### 双Agent模拟

双Agent模式允许用户与模拟的对方进行对话练习：

| Agent | 角色 | 功能 |
|-------|------|------|
| 用户Agent | 用户自己 | 输入回复，选择策略版本 |
| 对方Agent | 模拟的对方 | 根据用户回复生成反应，模拟真实对话 |

### 情绪追踪

实时追踪对话中的情绪变化：

| 情绪类型 | 识别特征 | 应对建议 |
|----------|----------|----------|
| 积极 | 使用正面词汇、表情 | 继续当前策略 |
| 中性 | 平淡表达、无明显情绪 | 观察后续反应 |
| 消极 | 使用负面词汇、指责 | 调整策略，安抚情绪 |
| 愤怒 | 使用强烈语气、感叹号 | 暂停对话，冷静处理 |

### 自由模式

**适用场景**：日常使用，简单场景
**特点**：
- 用户直接输入场景描述
- 系统自动完成全流程分析
- 无需额外操作

**流程**：
```
用户输入 → 意图识别 → 关系分析 → 三版本生成 → 反应预测 → 保存案例
```

### 引导模式

**适用场景**：复杂场景，需要深入分析
**特点**：
- 分步骤引导用户输入
- 提供结构化分析框架
- 用户可以调整分析结果

**流程**：
```
步骤1: 输入场景 → 步骤2: 确认意图 → 步骤3: 确认关系 → 步骤4: 选择版本 → 步骤5: 预测反应
```

### 压力模式

**适用场景**：紧急场景，需要快速响应
**特点**：
- 跳过非核心步骤
- 优先生成核心回复
- 简化分析流程

**流程**：
```
用户输入 → 快速意图识别 → 快速关系分析 → 生成最优版本 → 保存案例
```

## 设计决策

### 三模式设计的原因

**用户需求差异**：
- 新手用户：需要引导
- 熟练用户：需要自由
- 紧急用户：需要速度

**场景复杂度**：
- 简单场景：自由模式即可
- 复杂场景：需要引导模式
- 紧急场景：需要压力模式

### 双Agent模拟的价值

**练习价值**：
- 用户可以提前练习对话
- 熟悉不同策略的效果
- 提高实际社交能力

**风险降低**：
- 在安全环境中练习
- 无需担心实际后果
- 可以尝试多种策略

### 情绪追踪的必要性

**实时反馈**：
- 帮助用户了解对方情绪
- 及时调整策略
- 避免冲突升级

**学习价值**：
- 用户可以学习识别情绪
- 了解不同策略对情绪的影响
- 提高情绪管理能力

### 命令系统的设计

采用 `/command` 格式的原因：
- 清晰区分命令和场景输入
- 便于记忆和使用
- 支持快速操作

### 核心函数

**generateResponses(scenario)**

```javascript
async function generateResponses(scenario) {
  const intentResult = await recognizeIntent(scenario);
  const relationResult = await analyzeRelationship(scenario, 'hybrid');
  const responses = await generateThreeVersions(scenario, intent, relation);
  
  return { intentResult, relationResult, responses };
```

## 局限性

### 当前局限

1. **双Agent模拟简化**：对方Agent的反应基于预设规则，不够真实
2. **情绪追踪简单**：仅基于关键词识别，无法理解复杂情绪
3. **对话历史有限**：模拟对话仅支持有限轮次
4. **场景覆盖有限**：模拟场景基于预设数据，无法动态生成
5. **个性化不足**：所有用户使用相同的模拟逻辑

### 改进方向

1. **真实Agent模拟**：使用LLM驱动对方Agent，提高真实性
2. **深度学习情绪识别**：引入情感分析模型，提高情绪识别准确性
3. **长对话支持**：支持多轮对话模拟，记录完整对话历史
4. **动态场景生成**：根据用户输入动态生成模拟场景
5. **个性化模拟**：根据用户特征和偏好定制模拟体验
