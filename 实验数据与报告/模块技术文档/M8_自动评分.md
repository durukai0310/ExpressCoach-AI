# M8 评估模块

## 功能概述

评估模块（M8）是 ExpressCoach 的效果量化模块，负责对系统生成的回复进行质量评估。该模块采用 LLM-as-Judge 策略，实现自动化评分和效果验证。

**核心功能**：
- 5维度评分：意图达成度、关系维护度、表达自然度、策略适当性、可操作性
- 支持单条评估和批量评估
- 计算评分者间信度（Pearson r、Cohen's Kappa）
- 生成评估报告和统计数据
- 支持多评估者对比分析

**设计目标**：
- LLM vs 人工相关性 ≥ 0.75
- 评分一致性良好（Cohen's Kappa ≥ 0.6）
- 支持批量评估

## 核心算法

### 算法架构

模块采用 **LLM-as-Judge** 策略，使用 DeepSeek API 进行自动评分：

```
┌─────────────────────────────────────────────────────────────┐
│                    评估流程                                  │
├─────────────────────────────────────────────────────────────┤
│  输入: 场景 + 关系 + 回复                                    │
│       │                                                     │
│       ▼                                                     │
│  ┌──────────────┐                                          │
│  │ 构建评估Prompt│  → 填充场景、关系、回复到评分模板           │
│  └──────┬───────┘                                          │
│         │                                                  │
│         ▼                                                  │
│  ┌──────────────┐                                          │
│  │ 调用DeepSeek │  → 使用JUDGE_PROMPT提示词                  │
│  └──────┬───────┘                                          │
│         │                                                  │
│         ▼                                                  │
│  ┌──────────────┐                                          │
│  │ 解析评分结果  │  → 提取5维度评分和总分                      │
│  └──────┬───────┘                                          │
│         │                                                  │
│         ▼                                                  │
│  输出: 各维度评分、总分、评分理由                              │
└─────────────────────────────────────────────────────────────┘
```

### 评分维度定义

| 维度 | 权重 | 1分 | 3分 | 5分 |
|------|------|-----|-----|-----|
| 意图达成度 | 25% | 完全没表达意图 | 部分表达但不完整 | 意图清晰完整传达 |
| 关系维护度 | 25% | 明显伤害关系 | 中性不影响 | 增进信任和好感 |
| 表达自然度 | 20% | 生硬像机器翻译 | 基本通顺可接受 | 像真人说话，接地气 |
| 策略适当性 | 20% | 策略完全错误 | 策略可行但不够优 | 策略精准匹配关系 |
| 可操作性 | 10% | 没法直接使用 | 需要修改才能用 | 可以直接复制使用 |

### 总分计算

```
总分 = (意图达成度 × 0.25) + (关系维护度 × 0.25) + 
       (表达自然度 × 0.20) + (策略适当性 × 0.20) + 
       (可操作性 × 0.10)
```

### 提示词设计

JUDGE_PROMPT 包含以下核心要素：
- 明确的角色定义：中文社交表达质量评估专家
- 详细的评分标准：每个维度的1/3/5分描述
- 结构化输出格式：JSON格式，包含评分、总分和理由
- 输入变量：场景、关系、回复

### 批量评估

支持批量处理多个场景：
1. 加载场景数据
2. 生成三版本回复
3. 逐一评估每个版本
4. 保存评估结果
5. 输出统计信息

### 信度计算

**Pearson 相关系数**：
```
r = Σ[(x - x̄)(y - ȳ)] / √[Σ(x - x̄)² × Σ(y - ȳ)²]
```

**Cohen's Kappa**：
```
κ = (Po - Pe) / (1 - Pe)
```
- Po：观察一致率
- Pe：期望一致率（随机一致率）

## 设计决策

### 为什么选择 LLM-as-Judge？

**传统评估方法的局限性**：
- 人工评估成本高、耗时长
- 难以大规模评估
- 评估者之间存在差异

**LLM-as-Judge 的优势**：
- 成本低、速度快
- 可大规模评估
- 一致性好
- 可重复

### 权重分配的依据

基于用户调研和社交心理学理论：
- **意图达成度（25%）**：核心目标，必须清晰表达
- **关系维护度（25%）**：社交场景的核心价值
- **表达自然度（20%）**：用户体验重要因素
- **策略适当性（20%）**：策略匹配关系是系统核心能力
- **可操作性（10%）**：辅助因素，直接使用价值

### 温度参数设置

选择 `temperature: 0.1` 的原因：
- 评分是确定性任务
- 需要稳定、一致的评分结果
- 避免随机性影响评分可靠性

### 5维度评分的选择

基于社交表达的核心要素：
1. **意图达成**：是否实现了用户的目标
2. **关系维护**：是否维护了社交关系
3. **表达自然**：是否像真人说话
4. **策略适当**：策略是否匹配关系
5. **可操作性**：是否可以直接使用

### 核心函数

**evaluateResponse(scenario, relation, response, evaluator)**

```javascript
async function evaluateResponse(scenario, relation, response, evaluator = "llm") {
  const prompt = JUDGE_PROMPT
    .replace('{scenario}', scenario)
    .replace('{relation}', relation)
    .replace('{response}', response);
  
  const { content, tokens } = await callDeepSeek(prompt, '', {
    temperature: 0.1,
    maxTokens: 500,
    maxRetries: 2
  });
  
  const result = parseResponse(content);
  
  return { raw: content, parsed: { ...result, evaluator }, tokens, error: null };
}
```

**batchEvaluate(inputFile, outputFile)**

批量评估函数，支持从文件加载场景并保存评估结果。

**calculateCorrelation(scores1, scores2)**

计算两组评分之间的 Pearson 相关系数和 Cohen's Kappa。

## 局限性

### 当前局限

1. **LLM 评分偏差**：LLM 可能存在评分偏差，如对正面回复评分偏高
2. **维度有限**：仅支持5个维度，无法评估更多维度（如创新性、幽默度）
3. **评分粒度粗**：1-5分的评分粒度不够精细
4. **缺乏上下文**：无法考虑对话历史和上下文信息
5. **文化假设**：基于中国文化背景，国际化场景可能不适用

### 改进方向

1. **偏差校正**：基于人工评分校准 LLM 评分模型
2. **扩展维度**：增加更多评分维度，如创新性、幽默度、文化适配度
3. **细粒度评分**：使用1-10分评分，提高评分精度
4. **上下文感知**：引入对话历史，支持上下文相关评估
5. **文化适配**：根据用户地区自动调整评分标准
