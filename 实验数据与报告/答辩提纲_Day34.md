### 2. 四维社交计算模型 (90s)

> 我们的核心技术是**四维社交计算模型**，将每一次社交互动分解为四个维度:

**四个维度:**

| 维度 | 含义 | 示例 |
|------|------|------|
| **关系距离** | 亲疏远近 | 挚友 vs 普通同事 |
| **权力差** | 上下级/平等 | 老板 vs 平级同事 |
| **利益关联** | 情感 vs 利益 | 借钱(强利益) vs 道歉(纯情感) |
| **场景敏感度** | 拒绝 vs 催促 | 拒绝借钱(高敏感) vs 催报告(中敏感) |

> 传统方法只看"关系类型"（朋友/同事/家人），我们用**四个连续维度**刻画每个场景的独特张力。

**关键创新:**
- **双重关系检测**: 同事+好友、室友+上级 → 自动加权合并，敏感度修正
- **上下文覆盖**: 金钱关键词 → 强制升级利益关联；服务投诉 → 调整权力差
- **规则(30%) + LLM(70%) 混合**: 规则锚定方向，LLM 精调细节

### 3. 六阶段推理链 + 多Agent沙盒 (90s)

> 我们的系统采用**六阶段推理链**:

```
用户输入
  ↓
M1 意图识别 → 拒绝/催促/反馈/设边界/求助
  ↓ (并行)
M2 关系判断 → 四维向量 + 双重关系检测
  ↓
M3 三版本并行生成 → 温和版/坚定版/高情商版
  ↓
M4 Jaccard 差异度检测 → 自动重试差异化不足的版本
  ↓
M5 反应预测 → 对方 4 种可能反应 + 应对建议
  ↓
格式化输出 + SQLite 持久化
```

> 特别展示**多Agent沙盒**（`src/sandbox/sandbox.js`）:
> - 模拟 5-10 轮对话回合
> - 虚拟对方根据社交画像自主反应
> - 教练 Agent 每 2 轮介入，提供策略调整建议
> - 支持 `guided`（教练引导）/`autopilot`（自主运行）两种模式

## 答辩常见问题准备

### Q1: 为什么不直接用 DeepSeek/ChatGPT？
**A**: 通用大模型不了解中国文化中的关系微妙性。"拒绝朋友借钱"在通用模型看来就是"say no politely"，但我们知道这涉及面子、人情、关系距离的精确计算。我们的四维模型+规则词典是通用模型不具备的。

### Q2: 准确率怎么保证？
**A**: 意图识别 100% (57/57 测试通过)，关系判断 95% (77/81)。混合模式让规则兜底 + LLM 纠偏，比纯 LLM 更可靠。

### Q3: 响应速度怎么解决？
**A**: 当前 ~10s 的主要瓶颈是 API 网络延迟。已实现意图+关系并行化。短期方案：高频场景缓存 (5min TTL)；长期方案：小模型本地部署意图识别。

### Q4: 和竞品最本质的差异是什么？
**A**: 竞品做的是"生成文字"，我们做的是"计算关系"。四个维度+双重关系检测+反应预测，这是一个完整的决策支持系统，不是聊天工具。

### Q5: 可扩展性如何？
**A**: 模块化架构，11 个独立模块。添加新意图类型只需扩展 `intent-rules.json` + 更新 prompt。多语言/跨文化适配只需替换规则词典 + SOUL.md。
